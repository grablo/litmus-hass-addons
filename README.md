# Litmus NVR Home Assistant Add-on

[Home Assistant](https://www.home-assistant.io/) add-on repository for [Litmus NVR](https://litmusnvr.com).

**Litmus NVR** adds AI search and alerts to the IP cameras you already have: find people and vehicles in your recordings, search by description, and get notified when something you care about appears.

## Installation

[![Open your Home Assistant instance and show the add add-on repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Flitmusnvr%2Flitmus-hass-addons)

Or go to **Settings > Apps > App store > ⋮ > Repositories** and add `https://github.com/litmusnvr/litmus-hass-addons`. Then find **Litmus NVR** in the store and press **Install**.

Open the local screen at `http://<your-home-assistant-host>:8128/`, or use [app.litmusnvr.com](https://app.litmusnvr.com). See the [documentation](litmus-nvr/DOCS.md).
