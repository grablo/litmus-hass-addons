# Litmus NVR

Litmus NVR adds AI search and alerts to the IP cameras you already have: find people and vehicles in your recordings, search by description, and get notified when something you care about appears.

## Installation

1. Install the add-on and press **Start**.
2. Open `http://<your-home-assistant-host>:8128/` and create the admin account. On first start the setup code is printed in the add-on **Log** tab.
3. Add your cameras and press **Start**.

You can also add the device at **[app.litmusnvr.com](https://app.litmusnvr.com)** to use it from anywhere.

## Open from the Home Assistant sidebar

After the add-on starts, **Litmus NVR** appears in the Home Assistant sidebar (turn on **Show in sidebar** on the add-on page if it is hidden). It opens the same screen without a second sign-in. Only Home Assistant administrators can open it.

Live video in the sidebar connects straight to this machine, so it works when Home Assistant is opened on your home network. Talking through a camera needs Home Assistant opened over HTTPS (a browser rule for the microphone).
