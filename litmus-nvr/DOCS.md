# Litmus NVR

Litmus NVR adds AI search and alerts to the IP cameras you already have: find people and vehicles in your recordings, search by description, and get notified when something you care about appears.

## Installation

1. Install the add-on and press **Start**.
2. Open `http://<your-home-assistant-host>:8128/` and create the admin account. On first start the setup code is printed in the add-on **Log** tab.
3. Add your cameras and press **Start**.

You can also add the device at **[app.litmusnvr.com](https://app.litmusnvr.com)** to use it from anywhere.
